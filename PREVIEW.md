# SMS Client Preview (Node.js)

## Where do I run this?

Run the commands in a terminal **inside this project folder**:

```bash
cd /workspace/AI-Stuff
```

## Start preview with Node.js

```bash
npm start
```

Then open:

- `http://127.0.0.1:8000/index.html`

## What you should see

- API base URL input and **Connect & load numbers** button.
- Phone number cards with a **Refresh** button on each card.
- Actions for requesting verification SMS and verifying code.
- Inbox panel for the selected number.

## Note

This page is only the front end. You still need your SMS backend API running for loading numbers/messages and verifying codes.
